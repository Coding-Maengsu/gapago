# UI 개선 요구사항

**작성일:** 2026-03-28
**상태:** 미구현

---

## 1. 분석 완료 후 타임라인 처리

- 분석이 끝나면 타임라인이 **접히고** 분석 결과가 **위로 올라오도록** 레이아웃 변경
- 현재: 타임라인이 결과 위에 남아있어 스크롤 필요

---

## 2. 분석 결과에 입력 옵션 표시

- 결과 화면 상단에 **어떤 옵션으로 분석했는지** 표시
  - 선택된 LLM Provider
  - 연도 범위
  - 출력 언어
  - 입력 쿼리
- 사용자가 어떤 설정으로 나온 결과인지 한눈에 파악 가능하도록

---

## 3. 연구 도메인(Domain) 옵션 완전 제거

- 현재 웹에 연구 도메인 선택 UI가 여전히 보임
- **완전히 제거** 필요 (HTML에서 삭제)

---

## 4. Dynamic 축 GAP 강조

- 연구 GAP 결과에서 **Dynamic** 축으로 도출된 GAP이 더 눈에 띄게 표시
- Dynamic은 해당 연구 질문에 특화된 축이므로 더 중요함
- 시각적 차별화 필요 (뱃지, 색상, 아이콘 등)

---

## 5. 분석 히스토리 실시간 반영

- 새 분석 시작 시 히스토리에 **즉시** 항목 추가 (새로고침 없이)
- **분석 중** 상태에서도 히스토리에 표시 (진행 중 표시)
- 현재: 새로고침해야 히스토리에 나타남

---

## 6. 분석 중 레이아웃 리디자인

### 6.1 상단 영역
- **맨 위**: 분석 중 상태 텍스트 + 세부 설명 + 경과 시간

### 6.2 하단 2분할 레이아웃
- **좌측**: 타임라인 (기존 세로 타임라인)
- **우측**: 실시간 결과 미리보기
  - 논문 검색 단계 → 논문 리스트 실시간 표시
  - 한계점 추출 단계 → 추출된 한계점 실시간 표시
  - GAP 도출 단계 → GAP 실시간 표시
  - 사용자가 **기다리는 동안 지루하지 않도록** 동적 콘텐츠 제공

---

## 7. 색상 및 디자인 개선

- 타임라인 완료 시 **초록색 → 다른 색상**으로 변경
- 전체적으로 디자인 퀄리티 향상
- 색상 조합 재고려 (현재 초록색 완료 표시가 마음에 안 듦)
