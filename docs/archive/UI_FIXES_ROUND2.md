# UI 수정사항 (2차)

**작성일:** 2026-03-29
**상태:** 미구현

---

## 1. 질문 분석 · 검색어 확장 단계에서 우측 미리보기 표시

- **현재**: 논문 검색 결과부터 우측 패널에 표시됨
- **개선**: 질문 분석 / 검색어 확장 단계에서도 우측 미리보기에 결과 표시
  - 정제된 쿼리 (refined_query)
  - 확장된 키워드 목록 (keywords)
  - 검색어 분석 결과 등

---

## 2. 한계점 추출 Progress Bar 개선

- **현재**: 백엔드에서 `report_progress()`로 progress 이벤트를 SSE로 보내고 있으나, 프론트엔드에 `updateProgress()` 함수가 미구현되어 아무것도 표시 안 됨
- **개선**: `updateProgress()` 구현하여 우측 미리보기에 실시간 진행 표시
  - "논문 분석 중... 3/15편 완료" + 프로그레스 바
  - "한계점 8개 발견" 실시간 카운트
  - 백엔드가 이미 `current`, `total`, `message` 필드를 보내고 있으므로 프론트만 구현

---

## 3. 연구 GAP 축(axis) 강조 방식 변경

- **현재**: Dynamic 축 GAP이 보라색으로 강조 + Fixed/Dynamic 뱃지 표시
- **문제**: 모든 축이 동적 생성이라 Fixed/Dynamic 구분이 무의미. 사용자에게 중요한 것은 "어떤 축이 사용되었는지"
- **개선**: Fixed/Dynamic 뱃지 제거 → **축 이름(axis_label) 자체를 색상 뱃지로 강조**
  - 같은 축의 GAP끼리 동일 색상으로 시각적 그룹핑
  - 축별 자동 색상 배정 (5~7색 팔레트)
  - GAP 목록 + 상세 패널 모두 축 뱃지 적용
  - 사용자가 "이 연구에서 어떤 축이 활용되었는지" 한눈에 파악 가능
