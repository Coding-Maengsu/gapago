### 웹 수정 사항

- 분석 과정 타임라인 중에 “한계점 품질 평가” → “한계점 평가”로 변경
- 한계점 추출 타임라인에서 나오는 e.g. “16 limitations found so far” 문구를 한국어로 표기하기
- 한계점 추출 progress bar 천천히 채워져서 다 되면 꽉 채워지는 형태(현재는 바로 꽉채워진 형태가 나오고 개수가 업데이트됨)로 변경. 한계점 추출 개수가 progress bar의 기준이 되었으면 좋겠음.
- 분석이 완료된 뒤, “이 분석방향으로 추가 탐색” 을 눌러도, 옵션을 선택해야 다음 분석으로 진행될 수 있도록 변경. 사용자가 옵션을 인지할 수 있도록 적절한 효과 추가 (e.g. 옵션창 강조)
- 분석 완료 후, 분석 결과 토글 펼친 상태에서 스크롤 내리면, 토글 밖으로 분석 결과가 삐져나옴. 스크롤은 토클 내에서만 할 수 있도록 변경
- 분석 결과 토글 내에서 세부 토글 삭제. 바로 관계도 시각화.
- 관계도 가독성 개선 - 마우스를 올리면 강조되는 효과는 유지. 마우스로 클릭하면 강조된 상태로 고정될 수 있도록 함.
- 현재 관계도가 3개의 섹션으로 나누어져 있음. 섹션을 나누지 말고 시각화 진행. 처음 분석 결과 도출 시에 각 논문, 한계점, GAP의 전체적인 연결관계 잘 보일 수 있도록 제시. 그 후 사용자가 확대하여 볼 수 있도록 함. 추가적인 시각적 효과 허용
- GAPAGO 로고 클릭 시, 새로운 분석 페이지가 아닌 렌딩 페이지로 연결
- 선별된 k개의 논문에 대하여 “이 논문의 한계점” 출력 형식 개선. 한계점과 인용구만 추출하여 가독성 있게 제시
- 추가 채팅 output 가독성 개선 - 현재 추가 채팅 진행 시에 답변으로 나온 텍스트가 가독성이 너무 떨어짐. 해당 부분 개선

### 기능 수정 사항 

- 한계점 말이 끊기고 있음. 끊지 말고 요약하여 확실히 끝맺음할 수 있도록 해야함.
- full text 논문을 가져올 수 없을 경우, 다음 순위의 가능한 논문 가지고 올 수 있게 하여 full text 추출 실패한 논문이 선정된 k개 내에서는 없어야 함.
