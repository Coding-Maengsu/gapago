# 관계도 리디자인 설계서
> Papers → Limitations → GAPs 관계도 UX/UI 개선 계획

---

## 1. 레퍼런스 분석 (마인드맵 스타일)

레퍼런스 이미지(AI 시대 학원 없이 영어 공부하기)의 핵심 특징:

| 요소 | 현재 관계도 | 레퍼런스 |
|------|------------|---------|
| 레이아웃 | 선형 나열 (좌→중→우) | 계층형 트리 (중심 → 방사형) |
| 노드 색상 | 타입별 단색 | **깊이(depth)별 색상** 구분 |
| 노드 형태 | 줌에 따라 변형 | 깊이별 고정 형태 (사각형/타원) |
| 텍스트 | 잘려서 표시 | 전체 텍스트 줄바꿈 표시 |
| 엣지 | 점선 스파게티 | 부드러운 곡선 (bezier) |
| 접기/펼치기 | 없음 | 노드별 `<` / `>` 토글 |
| 초기 뷰 | 전체 노출 | 핵심 노드만 노출, 나머지 collapse |

## 2. 많은 노드를 "확 들어오게" 하는 전략

### 핵심 아이디어: **"처음엔 GAP부터 보여줘라"**

논문이 많으면 Papers를 먼저 보여줬을 때 압도됨.  
대신 **가장 중요한 GAP 노드를 중심에 크게 두고**, 클릭하면 연결된 Limitations → Papers로 drill-down하는 방식.

```
초기 뷰 (GAP-centric)
────────────────────────────────────────────────────
[GAP 1: 전해질 화학공간 탐색...]  ──→  클릭하면
[GAP 2: 멀티모달 데이터 부족]           ↓
[GAP 3: ...]                    관련 Limitations 펼침
                                        ↓
                                관련 Papers 펼침
────────────────────────────────────────────────────
```

### 대안: **"Papers는 Collapse, GAP만 초기 노출"**

레퍼런스처럼 좌→우 방향을 유지하되:
- **초기 상태**: Papers(접힘) → Limitations(접힘) → GAPs(펼침)
- 사용자가 GAP 클릭 시 → 관련 Limitations만 펼침
- Limitation 클릭 시 → 관련 Papers만 펼침

### 시각적 임팩트를 위한 추가 장치

1. **GAP 노드를 크게**: 연결된 Limitation 수에 비례한 노드 크기
2. **진입 애니메이션**: 페이지 로드 시 GAP 노드들이 순서대로 fade-in
3. **연결 수 뱃지**: GAP 노드에 `"한계점 7개 연결됨"` 같은 뱃지 표시
4. **배경 색상 구분**: GAP 영역 / Limitation 영역 / Paper 영역을 배경 띠로 구분

## 3. 레이아웃 설계

### 3-1. 전체 구조

```
┌─────────────────────────────────────────────────────┐
│  [배경 띠: Papers]  [배경 띠: Limitations]  [배경 띠: GAPs] │
│                                                     │
│  [Paper1]──────[Lim A]──────────────[GAP-1 ★]      │
│               [Lim B]─────────────╱                │
│  [Paper2]──────[Lim C]───────────╱                 │
│               [Lim D]──────────────[GAP-2 ★★]      │
│  [Paper3]──────[Lim E]────────────╱                │
│                                                     │
└─────────────────────────────────────────────────────┘
```

### 3-2. GAP 중심 그루핑 레이아웃 알고리즘

```
1. 각 GAP의 y 위치를 먼저 결정 (GAP 수 기준 균등 분배)
2. 각 GAP에 연결된 Limitations를 해당 GAP의 y 위치 주변에 클러스터링
3. 각 Limitation에 연결된 Papers를 해당 Limitation 주변에 배치
4. 겹침 방지: D3의 forceSimulation 또는 dagre 레이아웃 사용
```

### 3-3. 줌 레벨별 표시 전략

| 줌 레벨 | Papers | Limitations | GAPs |
|---------|--------|-------------|------|
| 전체 보기 (< 0.4) | 점(dot)만 | 점(dot)만 | **텍스트 항상 표시** |
| 중간 (0.4 ~ 0.8) | 짧은 제목 | 짧은 텍스트 | 전체 텍스트 |
| 확대 (> 0.8) | 전체 제목 | 전체 텍스트 | 전체 텍스트 |

> GAP 노드는 줌 레벨과 무관하게 항상 텍스트를 표시한다 (가장 중요한 정보이기 때문).

## 5. 엣지 디자인

### 5-1. 타입별 엣지 스타일

| 엣지 | 선 스타일 | 색상 | 투명도 |
|------|---------|------|--------|
| Paper → Limitation | 곡선 실선 | `#94A3B8` (회색) | 0.6 |
| Limitation → GAP | 곡선 실선 | **GAP별 고유 색상** | 0.7 |
| 비활성 엣지 | 동일 | 동일 | **0.05** (거의 투명) |

### 5-2. GAP별 엣지 색상 팔레트

```javascript
const gapColorPalette = [
  "#3B82F6",  // blue
  "#10B981",  // emerald
  "#F59E0B",  // amber
  "#EF4444",  // red
  "#8B5CF6",  // violet
  "#06B6D4",  // cyan
  "#F97316",  // orange
];
// GAP 인덱스 → 색상 매핑
const gapColor = (gapIndex) => gapColorPalette[gapIndex % gapColorPalette.length];
```

### 5-3. Bezier 곡선 엣지

```javascript
// D3 곡선 생성기 (수평 bezier)
const linkPath = d3.linkHorizontal()
  .x(d => d.x)
  .y(d => d.y);

// 또는 커스텀 곡선 (제어점 조절)
function drawEdge(source, target) {
  const midX = (source.x + target.x) / 2;
  return `M ${source.x} ${source.y}
          C ${midX} ${source.y}, ${midX} ${target.y},
            ${target.x} ${target.y}`;
}
```

## 6. 인터랙션 설계

### 6-1. 클릭 인터랙션 (Focus Mode)

```
노드 클릭 시:
  1. 클릭된 노드 → 강조 (scale up 1.1x, stroke 두껍게)
  2. 직접 연결된 엣지 → 완전 불투명 + 색상 강조
  3. 직접 연결된 노드 → 약한 강조
  4. 나머지 모든 노드/엣지 → opacity 0.05 (dim)
  5. 다시 클릭 또는 빈 공간 클릭 → 원상복구
```

```javascript
function focusNode(selectedId) {
  const connected = getConnectedNodes(selectedId);
  
  svg.selectAll(".node")
    .transition().duration(200)
    .attr("opacity", d => connected.has(d.id) ? 1.0 : 0.05);
  
  svg.selectAll(".edge")
    .transition().duration(200)
    .attr("opacity", d => 
      d.source.id === selectedId || d.target.id === selectedId ? 1.0 : 0.05
    )
    .attr("stroke-width", d =>
      d.source.id === selectedId || d.target.id === selectedId ? 2.5 : 1
    );
}
```

### 6-2. 접기/펼치기 (Collapse/Expand)

레퍼런스 이미지의 `<` / `>` 버튼과 동일하게 구현:

```javascript
// 노드 상태 관리
const nodeState = new Map(); // nodeId → { collapsed: boolean }

function toggleCollapse(nodeId) {
  const state = nodeState.get(nodeId);
  state.collapsed = !state.collapsed;
  
  // 연결된 자식 노드들 숨김/표시
  const children = getChildNodes(nodeId);
  children.forEach(child => {
    d3.select(`#node-${child.id}`)
      .transition().duration(300)
      .attr("opacity", state.collapsed ? 0 : 1)
      .attr("pointer-events", state.collapsed ? "none" : "all");
  });
  
  // 접힌 자식 수 뱃지 업데이트
  updateCollapseBadge(nodeId, state.collapsed ? children.length : 0);
  
  // 레이아웃 재계산
  recomputeLayout();
}
```

### 6-3. 초기 진입 애니메이션

```javascript
function playEntryAnimation() {
  // 1단계: GAP 노드 먼저 등장 (0~300ms)
  svg.selectAll(".node-gap")
    .attr("opacity", 0)
    .attr("transform", d => `translate(${d.x + 30}, ${d.y})`)
    .transition().duration(400).delay((d, i) => i * 80)
    .attr("opacity", 1)
    .attr("transform", d => `translate(${d.x}, ${d.y})`);
  
  // 2단계: Limitation 노드 등장 (300~600ms)
  svg.selectAll(".node-limitation")
    .attr("opacity", 0)
    .transition().duration(350).delay((d, i) => 300 + i * 50)
    .attr("opacity", 1);
  
  // 3단계: 엣지 그리기 (600ms~)
  svg.selectAll(".edge")
    .attr("stroke-dashoffset", function() { return this.getTotalLength(); })
    .attr("stroke-dasharray", function() { return this.getTotalLength(); })
    .transition().duration(500).delay(600)
    .attr("stroke-dashoffset", 0);
  
  // 4단계: Paper 노드 등장 (800ms~)
  svg.selectAll(".node-paper")
    .attr("opacity", 0)
    .transition().duration(300).delay((d, i) => 800 + i * 30)
    .attr("opacity", 1);
}
```

## 7. 기술 스택 및 구현

### 7-1. 권장 라이브러리

| 역할 | 라이브러리 | 이유 |
|------|----------|------|
| 그래프 렌더링 | **D3.js v7** | 완전한 커스터마이징 가능 |
| 계층 레이아웃 | **d3-hierarchy** or **dagre** | DAG 레이아웃 자동 계산 |
| 줌/패닝 | **d3-zoom** | 내장, 성능 좋음 |
| 엣지 번들링 (선택) | **d3-chord** or **@antv/g6** | 엣지 겹침 해소 |

### 7-2. 추천 레이아웃: `dagre-d3`

```javascript
import * as dagre from "dagre";

const g = new dagre.graphlib.Graph();
g.setGraph({ rankdir: "LR", ranksep: 120, nodesep: 40 });

// 노드 추가
papers.forEach(p => g.setNode(p.id, { width: 160, height: 36, type: "paper" }));
limitations.forEach(l => g.setNode(l.id, { width: 120, height: 50, type: "limitation" }));
gaps.forEach(gap => g.setNode(gap.id, { width: 220, height: 70, type: "gap" }));

// 엣지 추가
edges.forEach(e => g.setEdge(e.source, e.target));

// 레이아웃 계산
dagre.layout(g);

// 계산된 좌표로 D3 렌더링
```

### 7-3. 성능 최적화 (노드 수 많을 때)

```javascript
// 1. Canvas 혼합 렌더링: 엣지는 Canvas, 노드는 SVG
// → 엣지가 수백 개여도 렌더링 빠름

// 2. 가상화: 뷰포트 밖 노드 DOM에서 제거
const isInViewport = (node, transform) => {
  const { x, y, k } = transform;
  const screenX = node.x * k + x;
  const screenY = node.y * k + y;
  return screenX > -200 && screenX < window.innerWidth + 200 &&
         screenY > -200 && screenY < window.innerHeight + 200;
};

// 3. 디바운스: 줌/패닝 중 재렌더링 최소화
const debouncedUpdate = debounce(updateVisibleNodes, 16); // 60fps
```

## 8. 초기 뷰 UX 플로우 (최종 권장안)

```
[페이지 진입]
     ↓
[GAP 노드 3~5개 중앙 배치 + 진입 애니메이션]
[각 GAP 노드에 "연결된 한계점 N개" 뱃지 표시]
[Limitations/Papers는 모두 collapse 상태]
     ↓
[GAP 클릭]
     ↓
[해당 GAP과 연결된 Limitation 노드들만 펼침 (animate)]
[나머지 GAP들은 dim 처리]
     ↓
[Limitation 클릭]
     ↓
[해당 Limitation과 연결된 Paper 노드들 펼침]
     ↓
[Paper 클릭]
     ↓
[사이드패널에 논문 상세정보 표시]
     ↓
[전체보기 버튼으로 전체 그래프 복원]
```
