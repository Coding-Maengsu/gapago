## 수정사항 목록

### 1. 분석 중 타임라인 좌측 — 논문 검색 단계 중복 제거

**현재 상태**:
- "논문검색" 진행 시 `n편 중 k편 선택`이라는 텍스트와 함께, 아래에 논문 리스트가 추가로 표시됨

**문제**:
- 우측 패널에서 이미 검색된 논문을 보여주고 있으므로, 좌측 타임라인의 논문 리스트는 중복 정보임

**수정 내용**:
- 좌측 타임라인의 논문 검색 단계에서 **논문 리스트 부분을 삭제**
- `n편 중 k편 선택` 텍스트는 유지하되, 그 아래에 개별 논문 제목을 나열하지 않음
- 우측 패널이 유일한 논문 목록 표시 영역이 되도록 함

---

### 2. 분석 중 타임라인 우측 — 한계점 추출 표시 방식 변경

**현재 상태**:
- 한계점 추출 시 프로그레스바가 표시됨

**문제**:
- 한계점이 순차적으로 추출되므로, 전체 개수를 처음부터 예측하여 프로그레스바를 구성하는 것이 불가능
- 프로그레스바가 부정확한 정보를 전달할 수 있음

**수정 내용**:
- 프로그레스바 **제거**
- 대신, 한계점이 추출될 때마다 해당 한계점의 **"한줄 요약"을 순차적으로 표시**
- 각 한줄 요약은 **한 문장의 완결된 끝맺음이 있는 문장**으로 제시 (문장이 중간에 잘리지 않아야 함)
- 예시: `"본 연구는 단일 데이터셋에서만 평가되어 일반화 가능성이 제한됩니다."` (O)
- 예시: `"단일 데이터셋 평가로 인한..."` (X — 잘린 문장)
- 한계점이 하나씩 추가될 때 fade-in 등 간단한 애니메이션 적용 권장

> **참고**: 한줄 요약 텍스트의 생성 자체는 백엔드/LLM 쪽 작업일 수 있음. 프론트엔드에서는 전달받은 텍스트를 순차적으로 렌더링하는 UI만 담당. 만약 현재 스트리밍 응답에서 한줄 요약 필드가 없다면, 해당 필드 추가는 기능 브랜치에서 처리.

### 3. "이 분석방향으로 추가 탐색" — 옵션 선택 강제 + 강조 효과

**현재 상태**:
- 분석 완료 후 "이 분석방향으로 추가 탐색" 버튼을 누르면, 첫 분석과 동일한 옵션으로 바로 다음 분석이 진행됨

**문제**:
- 사용자가 옵션을 변경할 수 있다는 것을 인지하지 못함
- 옵션 선택 없이 자동 진행되므로 의도하지 않은 설정으로 분석이 시작될 수 있음

**수정 내용**:
- "이 분석방향으로 추가 탐색" 클릭 시, **옵션 선택 UI를 먼저 표시**
- 사용자가 옵션을 확인하고 **명시적으로 "분석 시작" (또는 유사한 확인 버튼)을 눌러야** 다음 분석 진행
- 옵션 UI가 나타날 때 사용자가 인지할 수 있도록 **시각적 강조 효과** 추가:
  - 옵션 영역에 하이라이트 또는 pulse 애니메이션
  - 옵션 영역으로 부드러운 스크롤 이동
  - 또는 옵션 영역 외 배경을 dim 처리하여 포커스 유도
- 이전 분석의 옵션 값을 **기본값으로 미리 채워두되**, 사용자가 변경 가능하도록 함

### 4. 분석 히스토리 — 논문 개수 `?` 표시 문제

**현재 상태**:
- 분석 히스토리에서 다른 분석을 하고 돌아오면, 분석결과 토글 내 최상단의 `k/n` 표시에서 `n`이 `?`로 표시됨

**문제**:
- 논문 총 개수 정보가 히스토리 복귀 시 유실되거나 로드되지 않음
- 사용자에게 불완전한 정보 제공

**수정 내용**:
- 원인 파악: 히스토리 데이터 로드 시 전체 논문 수(`n`) 값이 상태에 제대로 복원되는지 확인
  - 상태 관리(state)에서 해당 값이 저장/복원되지 않는 문제인지
  - API 응답에서 해당 필드가 누락되는 문제인지
- 해당 값이 히스토리 전환 후에도 정상적으로 표시되도록 수정
- `?` 대신 **로딩 중이면 스피너 또는 `-`**, **데이터가 있으면 정확한 숫자** 표시

### 5. 추가 채팅 창 — 말풍선 내 여백 및 줄바꿈 간격 조정

**현재 상태**:
- 말풍선 내 텍스트가 상하좌우 여백 없이 빡빡하게 출력됨
- 줄바꿈 시 간격이 지나치게 큼

**수정 내용**:

**(a) 말풍선 내부 패딩 추가**:
- 상하좌우 적절한 padding 부여 (예: `padding: 12px 16px` 또는 디자인 시스템에 맞게 조정)
- 텍스트가 말풍선 테두리와 충분한 거리를 두고 표시되어야 함

**(b) 줄바꿈 간격 축소**:
- 현재 줄바꿈(`\n` 또는 `<br>`) 시 간격이 과도함
- `line-height`와 `margin-bottom` (paragraph 간격) 조정
- 일반 줄바꿈은 `line-height: 1.5~1.6` 수준
- 단락 간 간격은 `0.5em~0.75em` 수준으로 축소
- 현재 값 확인 후 적절히 조정할 것
